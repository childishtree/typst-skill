# 0.5.0

## Text and Layout

- Added [`raw`](../reference/text/raw.md) syntax highlighting for many more languages
- Added support for Korean [numbering](../reference/model/numbering.md)
- Added basic i18n for a few more languages (NL, SV, DA)
- Improved line breaking for East Asian languages
- Expanded functionality of outline [`indent`](../reference/model/outline.md#parameters-indent) property
- Fixed footnotes in columns
- Fixed page breaking bugs with [footnotes](../reference/model/footnote.md)
- Fixed bug with handling of footnotes in lists, tables, and figures
- Fixed a bug with CJK punctuation adjustment
- Fixed a crash with rounded rectangles
- Fixed alignment of [`line`](../reference/visualize/line.md) elements

## Math

- **Breaking change:** The syntax rules for mathematical [attachments](../reference/math/attach.md#functions-attach) were improved: `$f^abs(3)$` now parses as `$f^(abs(3))$` instead of `$(f^abs)(3)$`. To disambiguate, add a space: `$f^zeta (3)$`.
- Added [forced size](../reference/math/sizes.md) commands for math (e.g., [`display`](../reference/math/sizes.md#functions-display))
- Added [`supplement`](../reference/math/equation.md#parameters-supplement) parameter to [`equation`](../reference/math/equation.md), used by [references](../reference/model/ref.md)
- New [symbols](../reference/symbols/sym.md): `bullet`, `xor`, `slash.big`, `sigma.alt`, `tack.r.not`, `tack.r.short`, `tack.r.double.not`
- Fixed a bug with symbols in matrices
- Fixed a crash in the [`attach`](../reference/math/attach.md#functions-attach) function

## Scripting

- Added new [`datetime`](../reference/foundations/datetime.md) type and [`datetime.today`](../reference/foundations/datetime.md#definitions-today) to retrieve the current date
- Added [`str.from-unicode`](../reference/foundations/str.md#definitions-from-unicode) and [`str.to-unicode`](../reference/foundations/str.md#definitions-to-unicode) functions
- Added [`fields`](../reference/foundations/content.md#definitions-fields) method on content
- Added `base` parameter to [`str`](../reference/foundations/str.md) function
- Added [`calc.exp`](../reference/foundations/calc.md#functions-exp) and [`calc.ln`](../reference/foundations/calc.md#functions-ln)
- Improved accuracy of [`calc.pow`](../reference/foundations/calc.md#functions-pow) and [`calc.log`](../reference/foundations/calc.md#functions-log) for specific bases
- Fixed [removal](../reference/foundations/dictionary.md#definitions-remove) order for dictionary
- Fixed `.at(default: ..)` for [strings](../reference/foundations/str.md#definitions-at) and [content](../reference/foundations/content.md#definitions-at)
- Fixed field access on styled elements
- Removed deprecated `calc.mod` function

## Command line interface

- Added PNG export via `typst compile source.typ output-\{n\}.png`. The output path must contain `\{n\}` if the document has multiple pages.
- Added `--diagnostic-format=short` for Unix-style short diagnostics
- Doesn't emit color codes anymore if stderr isn't a TTY
- Now sets the correct exit when invoked with a nonexistent file
- Now ignores UTF-8 BOM in Typst files

## Miscellaneous Improvements

- Improved errors for mismatched delimiters
- Improved error message for failed length comparisons
- Fixed a bug with images not showing up in Apple Preview
- Fixed multiple bugs with the PDF outline
- Fixed citations and other searchable elements in [`hide`](../reference/layout/hide.md)
- Fixed bugs with [reference supplements](../reference/model/ref.md#parameters-supplement)
- Fixed Nix flake
