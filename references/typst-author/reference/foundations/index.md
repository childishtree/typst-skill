# Foundations

Foundational types and functions.

Here, you'll find documentation for basic data types like [integers](int.md) and [strings](str.md) as well as details about core computational functions.

## Definitions

| Name | Description |
| --- | --- |
| [`arguments`](arguments.md) | Captured arguments to a function. |
| [`array`](array.md) | A sequence of values. |
| [`assert`](assert.md) | Ensures that a condition is fulfilled. |
| [`auto`](auto.md) | A value that indicates a smart default. |
| [`bool`](bool.md) | A type with two states. |
| [`bytes`](bytes.md) | A sequence of bytes. |
| [`calc`](calc.md) | Module for calculations and processing of numeric values. |
| [`content`](content.md) | A piece of document content. |
| [`datetime`](datetime.md) | Represents a date, a time, or a combination of both. |
| [`decimal`](decimal.md) | A fixed-point decimal number type. |
| [`dictionary`](dictionary.md) | A map from string keys to values. |
| [`duration`](duration.md) | Represents a positive or negative span of time. |
| [`eval`](eval.md) | Evaluates a string as Typst code. |
| [`float`](float.md) | A floating-point number. |
| [`function`](function.md) | A mapping from argument values to a return value. |
| [`int`](int.md) | A whole number. |
| [`label`](label.md) | A label for an element. |
| [`module`](module.md) | A collection of variables and functions that are commonly related to a single theme. |
| [`none`](none.md) | A value that indicates the absence of any other value. |
| [`panic`](panic.md) | Fails with an error. |
| [`plugin`](plugin.md) | Loads a WebAssembly module. |
| [`regex`](regex.md) | A regular expression. |
| [`repr`](repr.md) | Returns the string representation of a value. |
| [`selector`](selector.md) | A filter for selecting elements within the document. |
| [`std`](std.md) | A module that contains all globally accessible items. |
| [`str`](str.md) | A sequence of Unicode codepoints. |
| [`symbol`](symbol.md) | A Unicode symbol. |
| [`sys`](sys.md) | Module for system interactions. |
| [`target`](target.md) | Returns the current export target. |
| [`type`](type.md) | Describes a kind of value. |
| [`version`](version.md) | A version with an arbitrary number of components. |
