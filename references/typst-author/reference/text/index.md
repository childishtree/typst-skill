# Text

Text styling.

The [text function](text.md) is of particular interest.

## Definitions

| Name | Description |
| --- | --- |
| [`highlight`](highlight.md) | Highlights text with a background color. |
| [`linebreak`](linebreak.md) | Inserts a line break. |
| [`lorem`](lorem.md) | Creates blind text. |
| [`lower`](lower.md) | Converts a string or content to lowercase. |
| [`overline`](overline.md) | Adds a line over text. |
| [`raw`](raw.md) | Raw text with optional syntax highlighting. |
| [`smallcaps`](smallcaps.md) | Displays text in small capitals. |
| [`smartquote`](smartquote.md) | A language-aware quote that reacts to its context. |
| [`strike`](strike.md) | Strikes through text. |
| [`sub`](sub.md) | Renders text in subscript. |
| [`super`](super.md) | Renders text in superscript. |
| [`text`](text.md) | Customizes the look and layout of text in a variety of ways. |
| [`underline`](underline.md) | Underlines text. |
| [`upper`](upper.md) | Converts a string or content to uppercase. |
