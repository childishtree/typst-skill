# Layout

Arranging elements on the page in different ways.

By combining layout functions, you can create complex and automatic layouts.

## Definitions

| Name | Description |
| --- | --- |
| [`align`](align.md) | Aligns content horizontally and vertically. |
| [`alignment`](alignment.md) | Where to align something along an axis. |
| [`angle`](angle.md) | An angle describing a rotation. |
| [`block`](block.md) | A block-level container. |
| [`box`](box.md) | An inline-level container that sizes content. |
| [`colbreak`](colbreak.md) | Forces a column break. |
| [`columns`](columns.md) | Separates a region into multiple equally sized columns. |
| [`direction`](direction.md) | The four directions into which content can be laid out. |
| [`fraction`](fraction.md) | Defines how the remaining space in a layout is distributed. |
| [`grid`](grid.md) | Arranges content in a grid. |
| [`h`](h.md) | Inserts horizontal spacing into a paragraph. |
| [`hide`](hide.md) | Hides content without affecting layout. |
| [`layout`](layout.md) | Provides access to the current outer container's (or page's, if none) dimensions (width and height). |
| [`length`](length.md) | A size or distance, possibly expressed with contextual units. |
| [`measure`](measure.md) | Measures the layouted size of content. |
| [`move`](move.md) | Moves content without affecting layout. |
| [`pad`](pad.md) | Adds spacing around content. |
| [`page`](page.md) | Layouts its child onto one or multiple pages. |
| [`pagebreak`](pagebreak.md) | A manual page break. |
| [`place`](place.md) | Places content relatively to its parent container. |
| [`ratio`](ratio.md) | A ratio of a whole. |
| [`relative`](relative.md) | A length in relation to some known length. |
| [`repeat`](repeat.md) | Repeats content to the available space. |
| [`rotate`](rotate.md) | Rotates content without affecting layout. |
| [`scale`](scale.md) | Scales content without affecting layout. |
| [`skew`](skew.md) | Skews content. |
| [`stack`](stack.md) | Arranges content and spacing horizontally or vertically. |
| [`v`](v.md) | Inserts vertical spacing into a flow of blocks. |
